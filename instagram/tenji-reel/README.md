# 展示ブース リール

法政大学・Snow Crystal が過去に獲得した賞状・メダルの展示と、「選手の記録に挑戦コーナー」（5種目を体験）の紹介リール。1080×1920・10秒。

| 秒 | 場面 |
|---|---|
| 0〜2 | 暗闇のトロフィーにスポットライト「法政大学・Snow Crystal が勝ち取った 本物を、目の前で。」 |
| 2〜6 | ギャラリー（トロフィー・メダル・賞状）を横に移動。「過去に獲得した賞状・メダルを展示」。観覧者の吹き出し（これ本物…!? など） |
| 6〜8.3 | 「選手の記録に挑戦コーナー 5種目を体験!」握力・立ち幅跳び・反復横跳び・垂直跳び・眼球運動テストのカード。「キミの記録は、選手に届くか!?」 |
| 8.3〜10 | 「トロフィーも、メダルも、選手も ホンモノに会おう!」バドミントンパーク2026・11.23 |

- 選手の記録は「???」にしています。数値を出す場合は `// challenge` の「選手の記録：???」を書き換えます
- 場面の開始秒は `index.html` 冒頭の `CONFIG.scenes`
- 書き出し: `python render.py`（文字なし版は `--notext`）。準備は `../item-cards-reel/README.md` と同じです
