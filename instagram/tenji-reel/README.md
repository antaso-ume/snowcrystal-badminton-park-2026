# 展示ブース リール

法政大学・Snow Crystal が勝ち取ったトロフィー・メダルの展示と、現役選手の身体能力に挑戦するコーナーの紹介リール。1080×1920・10秒。

| 秒 | 場面 |
|---|---|
| 0〜2 | 暗闇のトロフィーにスポットライト「法政大学・Snow Crystal が勝ち取った 本物を、目の前で。」 |
| 2〜6 | ギャラリーを横に移動。観覧者の吹き出し（これ本物…!? など） |
| 6〜8.3 | 「現役選手の身体能力に、挑戦!」パワーメーターが「現役選手」の線のあと少し手前まで上がる。種目は未定なので「種目は当日のお楽しみ!」 |
| 8.3〜10 | 「トロフィーも、メダルも、選手も ホンモノに会おう!」バドミントンパーク2026・11.23 |

- 挑戦の種目が決まったら、場面3（`// challenge`）を差し替えます
- 場面の開始秒は `index.html` 冒頭の `CONFIG.scenes`
- 書き出し: `python render.py`（文字なし版は `--notext`）。準備は `../item-cards-reel/README.md` と同じです
