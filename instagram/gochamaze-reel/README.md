# ごちゃまぜバドミントン リール

法政大学・Snow Crystal の選手と参加者を全員まぜて2チームを作り、「1球打ったら即交代」で対戦する企画の紹介リール。1080×1920・10秒。

| 秒 | 場面 |
|---|---|
| 0〜2.2 | 法政大学・Snow Crystal・キミ（参加者）が集まる「全員、ごちゃまぜ!」 |
| 2.2〜5.0 | シャッフルして ブルーチーム VS オレンジチーム に分かれる（チームの中は法政・SC・参加者がまざったまま） |
| 5.0〜8.3 | 「1球打ったら、即交代!」 |
| 8.3〜10 | 「法政大学・Snow Crystal の選手と チームを組もう!」バドミントンパーク2026・11.23 |

- チーム名は仮。`index.html` 冒頭の `CONFIG.teamA` / `CONFIG.teamB` を書き換えると変わります
- 各場面の開始秒も `CONFIG.scenes` で調整できます
- 書き出し: `python render.py`（文字なし版は `--notext`）。準備は `../item-cards-reel/README.md` と同じです
