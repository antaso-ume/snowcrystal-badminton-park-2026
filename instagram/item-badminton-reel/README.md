# アイテムバドミントン リール

くじ引きボックスからアイテムのカードが飛び出し、カードが流れてエンディングへつながるリールです。1080×1920・10秒。

| 秒 | 場面 |
|---|---|
| 0〜3 | 「法政大学 と Snow Crystal の 選手が使うのは…?」くじ引きボックスが震えて、カードがポーンと飛び出す |
| 3〜8.3 | シルエットカードが右から左へ流れる「何が出るかは、運しだい」。最後に「最高難易度?!」カード |
| 8.3〜10 | 「法政大学・Snow Crystal の選手に 勝てるか!?」バドミントンパーク2026・11.23 |

## ファイル

- `index.html` … 本体。冒頭の `CONFIG` でカードの順番・速さ・場面の秒数を調整できます
- `lib.js` … イラスト（箱・終わりの画面など）と共通の部品
- `silhouettes.js` … 写真から作ったシルエット
- `render.py` … mp4 書き出し（`python render.py` / 文字なし版は `--notext`）

プレビューは `index.html` をブラウザで開くだけです。書き出しの準備は `../item-cards-reel/README.md` と同じです。
