# アイテムバドミントン リール

1本目のリール（しゃもじで打つ → アイテム → 箱 → 日付）の「アイテムが流れる場面」を、
写真のシルエットカードが流れる演出（`../item-cards-reel`）に差し替えたものです。1080×1920・10秒。

| 秒 | 場面 |
|---|---|
| 0〜2 | しゃもじでシャトルを打つ「ラケット、使いません。」 |
| 2〜7 | シルエットカードが右から左へ流れる「何で打つかは、運しだい」。最後に「最高難易度?!」カード |
| 7〜8.6 | 箱に手を入れる「選手は“最高難易度”から…?」 |
| 8.6〜10 | バドミントンパーク2026・11.23 |

## ファイル

- `index.html` … 本体。冒頭の `CONFIG` でカードの順番・速さ・場面の秒数を調整できます
- `lib.js` … イラスト（しゃもじ・箱・終わりの画面など）と共通の部品
- `silhouettes.js` … 写真から作ったシルエット
- `render.py` … mp4 書き出し（`python render.py` / 文字なし版は `--notext`）

プレビューは `index.html` をブラウザで開くだけです。書き出しの準備は `../item-cards-reel/README.md` と同じです。
